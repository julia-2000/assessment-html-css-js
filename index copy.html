Task Manager System

Instructions for using the Task Manager

Add New Task

Create tasks (via a form) with a task name, due date, priority level (Low, Medium or High) and optional consultant (enter the exact role from a list).

Display Tasks

Tasks are listed, including name, due date, priority level and consultant. Each task includes controls to either complete or delete it:

  • Complete task: Select the control to mark tasks as complete. The task will remain visible with strikethrough formatting.
  • Delete task: Select the control to remove tasks no longer needed.

Search Tasks

Look up tasks by typing the exact task name to display results or the message ‘Task not found’.
